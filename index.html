TABLE 02 — PENGALAMAN

Pengalaman Kerja

Junior Web Developer · Kumon Putro Agung Agustus 2025 — Juni 2026

Merancang dan mengembangkan sistem internal berbasis web menggunakan Laravel untuk mendukung operasional lembaga bimbingan belajar, mencakup lebih dari 25 modul fungsional.

  • Membangun sistem autentikasi multi-peran (admin, staf, asisten pengajar, orang tua) lengkap dengan 2FA dan reset password otomatis via email.
  • Mengembangkan modul presensi siswa, staf, dan asisten, jadwal pengganti, serta penilaian tugas dan sikap belajar.
  • Membangun modul keuangan meliputi invoice, bukti pembayaran, dan payroll untuk mengotomatisasi proses manual.
  • Mengintegrasikan fitur impor/ekspor data siswa berbasis Excel untuk pengelolaan data dalam jumlah besar.
  • Mengimplementasikan notifikasi email otomatis (tagihan jatuh tempo, jadwal pengganti, akun terkunci).
